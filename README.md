# Docker Compose Starters / Starters Docker Compose

Ready-to-adapt Compose files for common stacks.

Ficheiros Compose prontos a adaptar para stacks comuns.

## Stacks

| Path | Description |
|------|-------------|
| `postgres-redis/docker-compose.yml` | PostgreSQL + Redis |

## Quick start / Início rápido

```bash
cd postgres-redis && docker compose up -d
```

Copy env examples, set passwords, and never commit real secrets.

Copia os exemplos de env, define passwords e nunca faças commit de segredos reais.
